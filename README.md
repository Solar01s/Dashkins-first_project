# Dashkins-first_project
This was my first programming project, where i learned basic syntax and became familiar with algorithms in general. The bot's goal is to try to predict the user's intent, but as it turned out, relying on letters isn't entirely practical.

# How does interaction withthe bot work:
The first_programm file is launched where the greeting and input
are activated in an infinite loop.

# Technical side:
It's pretty simple. There's a file with the bot's responses, and
the triggers the bot responds to are tight there main file.

# How it responds:
In an infinite loop after input, functions are executed and check
if the troggers match user's request. if the function finds a match,
it adds a random topic-specific response to the main response. if
no response is found, an error is triggered. Perhaps this is more
complicated, but back then I was trying to understand programming in
general.
